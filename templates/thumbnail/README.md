# Thumbnail template

Place Shorts cover / custom thumbnail guidance and source files here.

## Specs

- Aspect: **9:16** (or YouTube Shorts cover crop-safe)
- Brand name **Car Anatomy** readable at phone size
- One subject + one short title fragment
- No badge stacks, fake UI, or clutter

## Per episode

Copy a finished cover to `episodes/YYYY-NN-slug/thumbnail.png` and point `meta.json` → `thumbnailPath`.
