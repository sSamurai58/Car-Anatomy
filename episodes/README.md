# Episodes

One folder per Short: `YYYY-NN-slug/`

Example: `2026-01-mustang-v8-sound/`

## Suggested contents

```
brief.md
script-short.md
voice.mp3
clips/
short.mp4
thumbnail.png
meta.json
timeline.json   # optional ffmpeg assemble input
```

Copy from `templates/` when starting a new episode. Do not commit large media binaries unless intentionally versioning a trial render.
